# Customer Churn Analysis

## Project Overview
This project analyzes customer churn patterns using the Telco Customer Churn dataset.

## Objectives
- Understand customer churn behavior
- Identify factors affecting churn
- Generate business insights for customer retention

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset
- Total Customers: 7043
- Churned Customers: 1869
- Active Customers: 5174
- Churn Rate: 26.54%

## Key Findings
1. Approximately 26.5% of customers churned.
2. Month-to-Month contracts show higher churn.
3. Customers with longer tenure are more likely to stay.
4. Higher monthly charges are associated with churn.
5. Long-term contracts improve customer retention.
